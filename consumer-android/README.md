# BoundaryCast | Android consumer release candidate
Version 0.1.0-rc1. Existing public BoundaryCast Python/FastAPI product, market factory, contracts and provider seam are preserved unchanged. This is a separate Android consumer adaptation of the public claim-scope and evidence policies, pinned to original commit 584bea49d49e1b89a4c102655dc51a313da1f768. No private Gatekeeper V2 code or private math.

Open consumer-android/android in Android Studio using the same Java 25 / AGP 9.5 / Gradle 9.6 configuration as LicensePrep. SDK 36, min 26, application bytecode Java 17. The Gradle wrapper binary is copied by exact blob identity from the tested LicensePrep build. Run on emulator or Android phone. Choose "Check my location" and approve foreground location, or select the explicitly labeled Kansas example for an actual live NWS request. Internet connectivity is required. If a service fails, the app displays a withheld claim, not synthetic weather.

Native Java transport uses only api.weather.gov HTTPS, direct point/grid hourly forecasts, nearest eligible actual station observations, active alerts, bounded responses and timeouts. No OASSE backend or paid API, no account, no saved location history, no betting. Manual decimal coordinates supported. NWS data is public, rate limited, US coverage only, and availability is not guaranteed. No alert notification or background monitoring. The app shows official alerts first and preserves the distinction between area forecast and measured station values. The public consumer policy supports area/nearby scopes only; never claims exact or microclimate certainty. Alert check failure or missing/stale forecast causes abstention; severe/extreme official alert takes precedence. Original public thresholds of 90-minute observations and 10 km station distance retained; a 12-hour forecast update threshold and required alert check are explicit mobile-specific policies, not private calibration. Receipt is transient policy replay and optional SHA-256 digest, not original durable chain or signed proof.

Run `node tests.cjs` for deterministic policy fixtures. Native compilation, actual provider parsing, real device location, accessibility, screen rotation, offline/alert behavior, app permissions, signed AAB and Play declarations must be verified. Source checks alone do not qualify release. No app publishing, backend deployment or purchase performed.

The initial public mobile adapter intentionally abstains if an authoritative point lookup or alert check is unavailable; a confirmed severe or extreme official warning still takes precedence and is rendered before routine forecast lookups. No exact location/microclimate claims are enabled in RC1.
